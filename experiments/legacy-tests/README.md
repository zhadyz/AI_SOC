# Historical test sketches

These original files are retained for reference outside pytest testpaths. They
expected 78 features, obsolete payloads, undeployed external products, or turned
failed assertions into skips. They are not acceptance evidence. Run `pytest` for
offline regressions and `python scripts/smoke_test.py --full` for the supported
live workflow. External Wazuh/TheHive/Grafana UI tests require a separate lab.
